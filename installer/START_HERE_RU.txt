CDDA Mods — актуальный установочный пакет
========================================

Поддерживаемые цели этого пакета:

1. experimental-2026-09-23-0546
   e262adb299a7613b4aedc5f12c08fe0413c56a84

2. experimental-2026-10-01-1040
   3f7fb352bf492ba521bd9408a0c9f6ce239e8d83

Распакуйте архив целиком в отдельную папку и запустите INSTALL.cmd.
Администраторские права обычно не нужны.

UPDATE.cmd обновляет ранее установленные выбранные компоненты из этого пакета.

Отдельный profile:iznanka устанавливает «Изнанку» 0.2.0 и UndeadPeople Hybrid.
Для него нужен exact experimental-2026-10-06-1807 /
074aa98bd5be3de4c35f154082db32a0e63bb0f1. Включите мод при создании мира;
выберите UndeadPeople_0J_Hybrid_v3 в графике. При обновлении с 0.1.0 насосная
сохраняется; посёлок обнаруживается при входе или использовании детектора.
Состояние проверки: mods/iznanka/VALIDATION.md.

profile:all-content включает:
- AXIOM-7;
- Blazemod;
- Secronom + Secronom+;
- Aftershock Prime;
- Tankmod;
- UndeadPeople.

Aftershock Prime / Mind Over Matter compatibility устанавливается отдельно только
если нужен Mind Over Matter.

Advanced World Settings и Survivor Progression в этом репозитории являются
installer-disabled native source snapshots. Текущие NCMM host/native-модули
устанавливаются из отдельного репозитория NCMM.

Что делает установщик:
- определяет точный build игры;
- проверяет SHA-256 пакетов и payload;
- распаковывает/валидирует во временном коротком %TEMP%\CDM-*;
- не использует saves при проверке;
- сохраняет backup/journal в <папка игры>/_CDDA-Mods/transactions;
- при ошибке установки выполняет групповой rollback;
- не включает новые моды в существующий мир автоматически.

Короткий TEMP-путь специально используется для Windows PowerShell 5.1 и длинных
путей CatLauncher: глубокие каталоги Secronom не должны упираться в legacy
MAX_PATH.

На CDDA 2026-10-01-1040 реальная CatLauncher-установка profile:all-content уже
успешно прошла isolated validator и завершилась Exit code: 0.

Строка
  Validator capability: dependency mod_interactions = broken; exact-source defer required
может быть нормальной для версий CDDA, где upstream --check-mods неправильно
обрабатывает dependency mod_interactions. В этом случае installer откладывает
только затронутый граф на exact-source cata_test; это не отключение всех проверок.

Для отката:
  Install-Mods.ps1 -GameRoot 'ПУТЬ_К_ИГРЕ' -Rollback 'ИД_ТРАНЗАКЦИИ'

Не удаляйте <game>/_CDDA-Mods/transactions, пока нужны резервные копии.
