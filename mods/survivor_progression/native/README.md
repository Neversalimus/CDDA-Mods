# Survivor Progression 0.9.15

This directory is a preserved native source snapshot imported from the older
cumulative v8.7.3 line.

It is **not the current player-facing Survivor Progression module** and remains
installer-disabled in CDDA-Mods. Current Survivor mechanics/UI/state integration
and current NCMM host/API support are maintained in the separate
`Neversalimus/NCMM` repository.

The snapshot remains here for provenance/history and CI build reproducibility.
Do not substitute it for the newer NCMM-side module merely because this source
still compiles.
